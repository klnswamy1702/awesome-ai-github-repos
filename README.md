# AI Engineering Resources

A curated collection of GitHub repositories for learning AI engineering,
understanding large language models (LLMs), building practical AI
applications, exploring AI engineering tools, and preparing for
interviews.

The goal of this repository is to bring useful AI learning resources
together in one place---from foundational theory to hands-on
implementation.

## Learning Roadmaps and Curriculums

### 1. [Start AI Engineering](https://github.com/louisfb01/start-ai-engineering)

**Repository:** `louisfb01/start-ai-engineering`

**About:** A guide and roadmap for getting started with AI engineering
and progressing toward building production-oriented AI applications. It
covers modern AI engineering topics such as retrieval-augmented
generation (RAG), agents, the Model Context Protocol (MCP), and context
engineering.

**Best for:** Learners who want a structured starting point and an
overview of the AI engineering ecosystem.

### 2. [Learn AI Engineering](https://github.com/ashishps1/learn-ai-engineering)

**Repository:** `ashishps1/learn-ai-engineering`

**About:** A curated collection of learning resources for AI engineering
and large language models, including free courses, tutorials, and
articles. Resources span foundational mathematics, deep learning,
generative AI, and agentic AI.

**Best for:** Finding supplementary courses and explanations while
following a learning roadmap.

### 3. [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch)

**Repository:** `rohitg00/ai-engineering-from-scratch`

**About:** A hands-on learning resource focused on understanding and
implementing AI engineering concepts. Use it to explore model internals,
retrieval pipelines, and agent runtimes through code.

**Best for:** Learners who want to understand how AI systems work by
implementing core components.

## Suggested Learning Path

If your goal is to learn enough theory and then build practical AI
projects, use these repositories in the following order.

### Phase 1: Understand the Fundamentals

**Start with:** [Start AI
Engineering](https://github.com/louisfb01/start-ai-engineering) and
[Learn AI
Engineering](https://github.com/ashishps1/learn-ai-engineering)

Study the basics of LLMs, tokens, context windows, prompting,
embeddings, and Transformer architecture. Use the curated courses and
articles to fill gaps in your understanding.

**Practice:** Write a small Python program that calls an LLM API.
Experiment with prompts, system instructions, and model parameters.

### Phase 2: Learn by Implementing

**Use:** [AI Engineering from
Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) and
[Hands-On AI
Engineering](https://github.com/Sumanth077/Hands-On-AI-Engineering)

Work through code examples and practical projects. Focus on
understanding each component rather than copying a complete
implementation.

**Practice:** Build a document question-answering application that
chunks files, creates embeddings, retrieves relevant passages, and
answers questions using those passages.

### Phase 3: Explore AI Tools and Agents

**Use:** [AI Engineering
Toolkit](https://github.com/Sumanth077/ai-engineering-toolkit)

Explore frameworks and utilities for tool calling, agent workflows,
retrieval, evaluation, and observability. Select tools based on your
project's requirements rather than adopting every framework.

**Practice:** Build a research assistant that uses tools to collect
information and produces a structured Markdown report.

### Phase 4: Consolidate Your Knowledge

**Use:** [AI Engineering Interview
Questions](https://github.com/amitshekhariitbhu/ai-engineering-interview-questions)

Review fundamentals and practice explaining system design choices,
retrieval strategies, agent workflows, evaluation, reliability, and cost
trade-offs.

**Practice:** Document the architecture of one project, add tests and
evaluation examples, and explain its limitations and design decisions.

## Recommended Project Progression

1.  **LLM API playground** --- experiment with prompts and model
    settings.
2.  **Chat with documents** --- implement document loading, chunking,
    embeddings, retrieval, and source-grounded answers.
3.  **AI research assistant** --- combine tool calling, retrieval, and
    multi-step workflows.
4.  **Production-ready AI application** --- add an API, tests,
    evaluation, logging, tracing, security controls, and deployment.

## How to Use This Collection

-   Start with one roadmap instead of trying to study every resource at
    once.
-   Build a small project after each major topic.
-   Keep notes on concepts, implementation decisions, and common failure
    modes.
-   Verify each repository's current README, license, dependencies, and
    maintenance status before using its code.
-   Treat repository descriptions in this document as brief summaries;
    consult the original repositories for the latest details.
